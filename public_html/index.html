Everything you need to ship production apps in a single dependency-free Go toolchain.

Architecture

Zero CGO & Zero Dependencies

Your go.mod stays completely clean. Cross-compile static binaries for Windows, macOS, Linux, BOSS Linux, Web, and Raspberry Pi without C toolchains.

Database

Dual-SQL Native Backend

Switch seamlessly between ACID-safe single-file db.LocalSQL, pure-Go wire-protocol db.MySQL, and credential-safe db.MySQLProxy with one fluent Query Builder.

UI Kit

Filament-Style CRUD Kit

Compose validated Form, searchable/sortable DataTable, AuthCard, Badge, and Toast widgets in lines of Go instead of boilerplate.

Mobile

1-Liner gopkin.yaml Permissions

Declare location, camera, or bluetooth once in gopkin.yaml. Gopkin generates AndroidManifest.xml, build.gradle, MainActivity.kt, Info.plist, and GopkinApp.swift at build time.

Hardware & IoT

Pure-Go GPIO & MQTT v3.1.1

Control Raspberry Pi / Linux SBC pins via zero-CGO sysfs GPIO (with desktop MockGPIO) and publish/subscribe telemetry over a stdlib TCP MQTT client.

India & Enterprise

First-Class BOSS Linux Target

Run gopkin build -t boss to emit a static Linux amd64 binary, .desktop launcher, and DEBIAN/control ready for Bharat Operating System Solutions.

Quickstart in 30 Seconds

Clean gopkin.yaml + app/main.gpk layout with zero native folder clutter.

Terminal
# 1. Scaffold a clean cross-platform app
gopkin new MyApp
cd MyApp

# 2. Run on Desktop or Live Web Target
gopkin run
gopkin run -t web

# 3. Build for any platform from one codebase
gopkin build -t boss
gopkin build -t web
gopkin build -t android
gopkin build -t ios
gopkin build -t iot
app/main.gpk
package main

import (
    . "gopkin"
    "gopkin/backend/db"
)

func main() {
    _ = db.Connect(db.LocalSQL("app_data.db"))
    rows, _ := db.Table("devices").OrderBy("id", "DESC").Get()

    Run("MyApp",
        Column(
            Heading("Devices"),
            DataTable([]TableColumn{
                Col("name", "Device"),
                Col("status", "Status"),
            }, rows),
        ),
    )
}
