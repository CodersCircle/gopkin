Gopkin Documentation

Gopkin is a 100% Pure-Go, zero-CGO, zero-external-dependency framework for shipping native apps across Android, iOS, Windows, Web, macOS, Linux, BOSS Linux, and IoT (ARM64) from a single codebase.

1-Line CLI Installation

PowerShell

Create & Run Your First App

Step 1 — Create a new app
gopkin new MyApp
Step 2 — Run on Desktop
gopkin run
Step 3 — Run live in Browser (http://127.0.0.1:8080)
gopkin run -t web

Project Structure

gopkin new MyApp scaffolds a minimal, clutter-free layout. Native mobile manifests, Gradle/Swift host bundles, web bundles, and BOSS Linux packages are generated strictly inside build/<target>/ at build time.

Directory Layout 
MyApp/
├── gopkin.yaml      # App name, bundle ID, version, entry, and unified permissions
└── app/
    └── main.gpk     # Declarative Pure-Go UI entry point
Backwards Compatibility: Projects using a legacy root app.gpk continue to resolve automatically.

Example gopkin.yaml

gopkin.yaml 
name: FieldScanner
id: com.example.fieldscanner
version: 1.0.0
entry: app/main.gpk
permissions:
  location: "Used to find nearby services"
  camera: "Used to scan QR codes"
  bluetooth: "Connect to smart sensors"
  notifications: "Deliver real-time alerts"
  storage: "Save offline device data"

UI & Filament-Style Plug-and-Play Kit

Write clean, declarative .gpk screens with reactive state, native keyboard focus (Input / TextInput), and Filament-style CRUD components (Form, Table / DataTable, AuthCard, Badge, Toast), plus monochrome styling and adaptive icons.

Interactive Form

app "Devices" {
    db.Local("app_data.db")

    Card("New Device") {
        Form(table: "devices") {
            Input("name", label: "Device Name", required: true)
            Select("status", options: ["on", "off"])
            Toggle("auto", label: "Auto Schedule", default: true)
            Submit("Save Device")
        }
    }
}
form := Form(
    TextField("name", "Device Name").Required(),
    SelectField("status", "Status", "on", "off"),
    ToggleField("auto", "Auto Schedule", true),
).SubmitLabel("Save Device").OnSubmit(func(v map[string]string) error {
    _, err := db.Table("devices").Insert(map[string]any{
        "name": v["name"], "status": v["status"],
    })
    return err
})

DataTable, Badge, Toast & AuthCard

Page("Devices") {
    Badge("Online", variant: "success")
    Toast("Synced with LocalSQL", variant: "info")

    Table("devices", columns: ["id", "name", "status"], search: true, pageSize: 10) {
        Action("Delete") { row -> db.Delete("devices", id: row.id) }
    }
}

Page("Login") {
    AuthCard("Sign In") { email, password ->
        auth.Login(email, password)
    }
}
rows, _ := db.Table("devices").OrderBy("id", "DESC").Get()

table := DataTable([]TableColumn{
    Col("id", "ID", 60), Col("name", "Device"), Col("status", "Status", 100),
}, rows).PageSize(10).Actions(
    TableAction("Delete", func(r map[string]any) {
        _, _ = db.Table("devices").Where("id", r["id"]).Delete()
    }),
)
badge := Badge("Online", "success")
toast := Toast("Synced with LocalSQL", "info")
login := AuthCard("Sign In", func(email, pass string) error { return nil })

Dual-SQL Native Backend (backend/db)

Switch between ACID-safe offline local storage, direct MySQL, and credential-safe HTTP proxy bridges with a single line — 100% Pure Go, zero CGO. 

// Pick any database mode in 1 line:
db.Local("app_data.db")                                  // Offline LocalSQL
db.MySQL("user:pass@tcp(127.0.0.1:3306)/myapp")          // Direct Live MySQL
db.MySQLProxy("https://db-bridge.myapp.com", "API_TOKEN") // Secure Mobile Proxy

// Fluent queries (auto-creates missing tables)
db.Insert("devices", { name: "Light 1", status: "on" })
lights = db.From("devices").Where("status", "on").OrderBy("id", "DESC").Limit(20)
db.Update("devices", where: { id: 1 }, set: { status: "off" })
db.Delete("devices", where: { id: 1 })
_ = db.Connect(db.LocalSQL("app_data.db"))
// or: db.Connect(db.MySQL("user:pass@tcp(127.0.0.1:3306)/myapp"))
// or: db.Connect(db.MySQLProxy("https://db-bridge.myapp.com", "API_TOKEN"))

id, _ := db.Table("devices").Insert(map[string]any{"name": "Light 1", "status": "on"})
rows, _ := db.Table("devices").Where("status", "on").OrderBy("id", "DESC").Limit(20).Get()
_, _ = db.Table("devices").Where("id", id).Update(map[string]any{"status": "off"})
_, _ = db.Table("devices").Where("id", id).Delete()

Unified Permissions API

Declare permissions once in gopkin.yaml and request them cleanly across Android, iOS, Desktop, and Web. At build time, Gopkin automatically generates build/android/AndroidManifest.xml and build/ios/Info.plist. 

onClick("Scan QR") {
    if AskPermission(Camera) == Granted {
        OpenScanner()
    }
}
// Supported: Location, Camera, Bluetooth, Notifications, Storage
if CheckPermission(PermCamera) != Granted {
    if AskPermission(PermCamera) == Granted {
        // Camera permission granted
    }
}
// Constants: PermLocation, PermCamera, PermBluetooth, PermNotifications, PermStorage

IoT & Hardware Kit (hardware/)

Control physical GPIO pins and connect to MQTT brokers using 100% Pure Go. hardware.OpenGPIO() uses Linux sysfs (/sys/class/gpio) on Raspberry Pi / Linux SBCs and falls back to MockGPIO on desktop.

Pure-Go GPIO & MQTT v3.1.1

app "SmartRelay" {
    gpio = hardware.OpenGPIO()
    mqtt = hardware.MQTT("127.0.0.1:1883")

    mqtt.Subscribe("home/light/1") { payload ->
        gpio.Write(17, payload == "ON")
    }
    Toggle("Living Light") { on -> mqtt.Publish("home/light/1", on) }
}
gpio := hardware.OpenGPIO()
defer gpio.Close()
_ = gpio.PinMode(17, hardware.PinOutput)
_, _ = gpio.Toggle(17)

mqtt := hardware.NewMQTTClient()
if err := mqtt.Connect("127.0.0.1:1883", "gopkin-node-1", "", ""); err == nil {
    defer mqtt.Disconnect()
    _ = mqtt.Subscribe("home/+/status", func(topic string, payload []byte) {})
    _ = mqtt.Publish("home/light1/status", []byte("ON"))
}
